# แปลง PDF → รูปภาพ (สำหรับเครื่องที่ไม่ได้เปิด Smart App Control)

สคริปต์นี้แปลงหน้าของ PDF คู่มือแต่ละไฟล์เป็นรูป PNG เพื่อนำไปใส่ในคู่มือบนเว็บ

> **ทำไมต้องรันบนเครื่องอื่น:** เครื่องหลักเปิด Smart App Control (SAC) ซึ่งบล็อกไฟล์
> native ที่ใช้เรนเดอร์รูป และ SAC ปิดแล้วเปิดกลับไม่ได้ (ต้องลง Windows ใหม่) จึงแนะนำ
> ให้รันบนโน้ตบุ๊กอีกเครื่อง / เครื่องที่ไม่ได้เปิด SAC / macOS / Linux แทน

## วิธีใช้

1. คัดลอกโฟลเดอร์ `tools/pdf-images` นี้ไปเครื่องที่จะรัน (ต้องมี Node.js 18+)
2. เอาไฟล์ PDF คู่มือทั้งหมดไปไว้ในโฟลเดอร์ย่อยชื่อ `pdfs` (หรือจะชี้ path เองก็ได้)
3. รัน:
   ```bash
   npm install
   node render.mjs
   # หรือชี้โฟลเดอร์ PDF เอง:
   node render.mjs "C:/Users/you/Desktop/SOP"
   ```
4. รูปจะออกที่ `output/<slug>/page-01.png, page-02.png, ...`
   โดยชื่อโฟลเดอร์ `<slug>` ตรงกับคู่มือในเว็บ (เช่น `edc-machine`, `yoowifi-service`)

## นำรูปเข้าระบบ

เปิด SOP Hub → **Admin → คู่มือ → แก้ไข** เอกสารที่ต้องการ → กดปุ่มแทรกรูปในตัวแก้ไข
แล้วอัปโหลดรูปจากโฟลเดอร์ `output/<slug>/` ไปวางแทนเครื่องหมาย `[📷 ภาพประกอบ: ...]`
(ดูรายการจุดที่ต้องใส่รูปได้ในไฟล์ `IMAGE_CHECKLIST.md`)

## ปรับความคมชัด

ในไฟล์ `render.mjs` แก้ค่า `SCALE` (ค่าเริ่มต้น 2 ≈ 144 DPI) เป็น 3 เพื่อให้รูปคมขึ้น (ไฟล์ใหญ่ขึ้น)

## หมายเหตุ

- ส่วนอ่าน PDF (pdf.js) ทดสอบแล้วทำงานได้ ส่วนเรนเดอร์เป็นรูปต้องใช้เครื่องที่ไม่บล็อก native binary
- สคริปต์เรนเดอร์ **ทั้งหน้า** ของ PDF เป็นรูป — เลือกเฉพาะหน้า/ครอบเฉพาะส่วนที่ต้องการตอนอัปโหลด
  (ถ้าต้องการครอบเฉพาะภาพ ใช้ Snipping Tool ครอบจากไฟล์ PNG ที่ได้อีกที)
